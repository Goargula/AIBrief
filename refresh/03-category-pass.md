# Phase 3: Category Pass

Load `refresh/categories.json` and run every audit independently. Category
searches must be performed even when the named-source pass already found many
stories. Treat each audit's `requiredSearches` and `primaryTargets` as a minimum,
then adapt them to current events and exact dates.

Audits:

- `models`: model releases and material capability changes.
- `papers`: research, benchmarks, datasets, evaluations, and AI for science.
- `funding`: rounds, acquisitions, investments, IPOs, debt, and new companies.
- `policy-safety`: policy, legal, labor, security, misuse, and public pushback.
- `infrastructure`: chips, compute, networking, memory, energy, and data centers.
- `products-adoption`: products, agents, developer tools, deployments, reports,
  operational outcomes, and workforce effects.
- `physical-ai`: robotics, autonomy, drones, industrial and embodied AI.
- `health-science`: healthcare, biology, drug discovery, and scientific use.
- `regional`: important smaller and non-U.S. ecosystem developments.

For each audit:

1. Run today, yesterday, exact-date, and 48-72 hour searches.
2. Run relevant primary-source and specialist searches.
3. Reuse direct-page evidence from Phase 2, but run category-targeted searches
   independently.
4. Add all material candidates to the ledger, including duplicates discovered by
   another pass.
5. Record important exclusions and mark the audit complete.

Run a 30-day catch-up for workforce restructurings, scaled deployments,
fraud/loss figures, and empirical adoption reports.
